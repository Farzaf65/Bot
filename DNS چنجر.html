کانفیگ وایرگارد

لیست DNS

هر کدوم رو انتخاب کنی، تو فیلدهای خانه وارد می‌شه. استفاده از لیست اجباری نیست.

هشدارها

  • این اپ فقط DNS رو عوض می‌کنه. فیلترشکن نیست و IP تو رو مخفی نمی‌کنه.
  • سرعت و پینگ بعد از تغییر DNS تضمین نمی‌شه و به شبکه و اپراتور بستگی داره.
  • اپ برای اعمال DNS از سرویس VPN اندروید استفاده می‌کنه. ترافیک تو ذخیره یا ارسال نمی‌شه.
  • با DNS ناشناس احتیاط کن. سرور DNS می‌تونه ببینه کدوم سایت‌ها رو باز می‌کنی.

سؤالات متداول

چرا اندروید کلید VPN نشون می‌ده؟

اپ‌های تغییر DNS بدون روت از همین سرویس استفاده می‌کنن. فقط درخواست‌های DNS تغییر می‌کنن و بقیه ترافیک مستقیم می‌ره.

اتصال برقرار نمی‌شه، چه کنم؟

آدرس DNS رو دوباره چک کن، یه DNS دیگه امتحان کن و مجوز VPN رو دوباره تأیید کن. اگه نشد، اینترنت گوشی رو یک بار قطع و وصل کن.

کدوم DNS برای بازی بهتره؟

بستگی به اپراتور داره. چند DNS رو روی همون اینترنتی که بازی می‌کنی امتحان کن و علاقه‌مندی‌هات رو ستاره بزن.

وایرگارد و DNS رو با هم می‌تونم استفاده کنم؟

از تنظیمات پیشرفته وایرگارد رو روشن کن. تو صفحه خانه گزینه استفاده همزمان ظاهر می‌شه. این حالت به شرایط اینترنت بستگی داره و ممکنه پینگ رو بالا ببره.

IPv6 رو باید روشن کنم؟

لازم نیست. IPv4 برای کار اپ کافیه و IPv6 فقط وقتی مفیده که شبکه‌ات پشتیبانی کنه.
